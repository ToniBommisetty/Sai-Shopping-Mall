# 🏬 Sai Shopping Mall — Node.js Store (v1)

The first version of my TO||NI clothing store: a storefront with user registration and login backed by **Node.js, Express and MongoDB**. The improved version, with account settings, OTP password reset and orders, is in [MyShopToni](https://github.com/ToniBommisetty/MyShopToni).

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## ✨ Features

- Responsive product storefront (HTML, CSS, JavaScript)
- User registration with **bcrypt** password hashing
- Login validated against MongoDB
- Form validation on the client side

## 🚀 Getting Started

```bash
git clone https://github.com/ToniBommisetty/Sai-Shopping-Mall.git
cd Sai-Shopping-Mall
npm install
node server.js          # needs MongoDB running locally on port 27017
```
